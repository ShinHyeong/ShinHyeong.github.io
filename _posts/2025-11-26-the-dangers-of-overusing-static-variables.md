# static 변수를 남용하면 안되는 이유 (유의점)

1. **static 변수와 인스턴스 변수의 차이점**
    - **static 변수**는 **메소드 영역**에 하나만 생성되어 **모든 객체가 공유**하는 변수이고,
    - **인스턴스 변수**는 **힙 영역**에 **객체마다 독립적으로 생성**되는 변수입니다.
2. **구체적인 문제점 (핵심)**
    - 그래서 모든 인스턴스 변수를 static 변수로 바꾸면, 모든 객체가 하나의 변수만 바라보고 **값을 덮어쓰기** 때문에 예상치 못한 결과가 나올 수 있습니다.
    - 또, **가변적인 값**을 static 변수에 저장하면, 멀티스레드 환경에서는 **여러 스레드가 동시에** 이 변수에 접근하며 **Race Condition**이 발생하여 **동기화 문제**와 함께 치명적인 오류를 일으킬 수 있습니다.
3. **올바른 사용법:**
    - 따라서 static 변수는 **값이 변하지 않는 상수**에 사용하는 것이 가장 바람직합니다. Java에서는 `public static final` 키워드를 사용해 상수로 선언함으로써 **안전하게 공유**할 수 있습니다.
    - 객체의 고유의 상태는 반드시 인스턴스 변수로 관리해야 합니다.
