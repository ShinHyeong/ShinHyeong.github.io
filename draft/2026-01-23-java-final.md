# final 키워드 : 변경 불가 선언

자바에서 final 키워드는 선언된 요소가 **더이상 변경될 수 없는** 최종 상태임을 의미할 때 사용합니다.

- 변수 : 재할당 금지, 값 변경 불가
- 메소드 : 오버라이딩 금지, 로직 변경 불가
- 클래스 : 상속 금지, 구조 변경 불가

## final 변수 : **재할당 금지**

로컬 변수든 멤버 변수든 final 키워드가 붙으면 변수 생성 후 초기화 이후에는 **값을 변경할 수 없는 상수**가 됩니다.

참조변수(객체)의 경우도, 주소값이 고정되기 때문에 새로운 객체를 재할당하는 것은 금지됩니다. 단, 주소값만 고정되기 때문에 **객체 내부 멤버나 필드값은 자유롭게 변경 가능**합니다.(=add/remove 가능)

```java
final List list = new ArrayList<>();

list = new ArrayList<>(); //ERROR
list.add('data'); //OK
```

## final 메소드 : 오버라이딩 금지(로직변경x)

자식 클래스에서 이 메소드를 재정의할 수 없습니다. 설계자가 처음 설계한 로직을 변경없이 그대로 유지하게 할 때 사용합니다.

## final 클래스 : 상속 금지(자식만들기x)

더이상 자식 클래스를 만들 수 없습니다. (extends 불가)
